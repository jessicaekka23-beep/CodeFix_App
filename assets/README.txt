Drop your own graphics here (optional):

  wallpaper.png  (or .jpg / .jpeg / .webp)   used as the desktop background, max ~2 MB

If no wallpaper is found, a pixel-art pastel scene (day, or night in dark theme) is drawn in code.
Set CODEPILOT_NO_THEME=1 to turn the whole retro theme off.

Fonts: Pixelify Sans, Silkscreen and VT323 load from Google Fonts, so the pixel look needs an internet
connection in the browser. Offline, the page falls back to a plain monospace font and still works.
